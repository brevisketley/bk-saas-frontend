Connect MetaTrader 5 to licence verification

REQUIRED SETUP

Your EA contacts the BK Corp Club licensing server to validate its licence. MT5 must allow this server in its WebRequest list.

https://bk-saas-backend.onrender.com
01Open Expert Advisors

In MetaTrader 5, select Tools → Options → Expert Advisors.

02Allow WebRequest

Tick “Allow WebRequest for listed URL(s)” to enable the EA to contact approved servers.

03Add the exact URL

Paste the server URL shown above into the list, select OK to save, then restart or reattach your EA if required.

Do not add guessed URLs. The confirmed server address for the current BK Corp Club EA licensing integration is https://bk-saas-backend.onrender.com. If validation still fails, capture the MT5 Experts and Journal messages for support.
